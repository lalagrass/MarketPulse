### 橫斷面動能指標盤點（2026-09-04 評估，結論：不新增）

社群與開源常見的動能指標盤點結果。**記錄在此是為了避免日後重複討論。**

| 指標 | 判定 | 理由 |
|---|---|---|
| KD / 隨機指標 | **不適用** | 單一標的的時序震盪指標，量的是「價格在自己近期區間的哪個位置」。輪動是橫斷面問題——兩個主題可以同時 KD 80 而相對大盤一個 +20% 一個 +2%。另有 (9,3,3) 參數與 20/80 門檻，全是 D10 要擋的可調把手 |
| RSC（Relative Strength Comparative） | **已具備** | 標的除以基準的比值線。`rs20` 本質上就是它的窗口版本 |
| Mansfield RS（Weinstein Stage Analysis） | **已涵蓋** | RSC 再對自身移動平均正規化，回答「相對強弱本身在不在改善」。`rank_delta_5` 已在名次空間涵蓋此維度 |
| RRG 的 RS-Ratio / RS-Momentum | **non-goal D3** | `rank` + `rank_delta` 已涵蓋雙軸概念的實用部分 |
| RSI 作為動能選股因子 | **不適用** | 那是策略不是指標，驗證需要完整回測（D2） |

**結論：橫斷面輪動的既有工具箱本來就小，而主要那一項已經在用。**
散戶熟悉的指標（KD、RSI、MACD、布林）幾乎都是單一標的的時序工具。

**更重要的推論：**sprint 001 發現 20 日尺度上結構不穩，那是**市場的性質，不是量測的缺口**。
若一個月前的名次對今天沒有解釋力，再加一個震盪指標也不會讓它變得有解釋力。
正確反應是知道它並照著讀（短端信、長端打折），不是找新指標把它填滿。

**2026-09-06 再確認（不重開）：**市面／OSS 主流仍是相對報酬→橫斷面排名（多窗
composite、IBD RS Rating、12−1、residual momentum、Elo 皆然）。004 的 σ 梯度
（k=1/+34.4σ → k=5/+25.4σ → k=20/+2.84σ）強化「問題在尺度不在統計量」。
除非 as-of 成分重測翻轉 k=20 讀法，否則不重開「換 rank」討論。sprint 005 改買
前向 Rank-IC 物證，不換 primary。

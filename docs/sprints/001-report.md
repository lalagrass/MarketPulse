## 本輪最重要的產出：第一個持續性讀數

141 個交易日（2026-01 → 2026-09）的 `market_daily` 統計：

| 期限 | 中位數 | 平均 | 標準差 |
|---|---|---|---|
| `rank_persistence_1` | 0.945 | 0.936 | 0.057 |
| `rank_persistence_5` | 0.773 | 0.731 | 0.177 |
| `rank_persistence_20` | **0.282** | 0.214 | **0.453** |

`dispersion` 平均 0.239、標準差 0.079。`persistence_20 > 0.5` 的交易日佔 27%。

**判讀：**

n=11 時，兩個獨立隨機排列的 Spearman ρ 標準差為 1/√10 ≈ 0.316。
單日 0.282 不到一個雜訊標準差。121 個觀測高度重疊（相鄰日共用 19/20 窗口），
有效獨立樣本約 6，標準誤約 0.18，平均 0.214 對應 t ≈ 1.2。
**20 日尺度的持續性，統計上與零無法區分。**

但觀測標準差 0.453 **大於**雜訊基準 0.316，且極值到 −0.918（約 −2.9 個雜訊標準差），
四分位數 −0.136 / +0.573 跨零。**這不是零附近的抖動，是正負之間的寬擺盪。**

**與資料相容的假說（未證實）：**若類股領導權約以月為週期輪動，
persistence_20 本來就該在同相位時為正、輪動後為負，淨平均接近零。
一個測量輪動的工具在該尺度上量到這個結果，可能正是量對了。

**分辨方法（sprint 002 第一件事）：**persistence_20 序列若呈週期性擺盪即為輪動，
若為隨機遊走則為雜訊。看該序列自身的自相關，或直接繪出。

**限制：**141 個交易日只涵蓋一個市場階段（含七月大跌與其後反彈）。
結論僅適用於觀察期，不可外推。

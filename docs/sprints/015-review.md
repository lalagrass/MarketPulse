### 5.4 `branch` 欄溢出（**本節初稿的診斷是錯的，已更正**）

```text
memory_passthrough/nand_price_passthrough誰贏都賺    5     +3.2% …
```

> **更正（2026-09-09）：**初稿寫「`branch` 欄沒有欄寬，與 009 `敘事`、012 `Momentum`
> 是同一個病的第三次」。**查了程式碼，錯了。**`baskets.py:112` 有
> `BRANCH_COL_WIDTH = 36`，欄寬存在。真正的成因是
> `memory_passthrough/nand_price_passthrough` 是 **41 個字元**，超過 36，
> 而 `product.py:126` 的 `_ljust` 是 `text + " " * max(0, width - _vislen(text))`
> ——**只補齊、不截斷**，溢出時 padding 為 0，下一欄直接接上去。

**真正的病是 `_ljust` 靜默溢出，而它是三個 renderer 共用的**：
`NAME_WIDTH`、`MOM_COL_WIDTH`、`NARRATIVE_COL_WIDTH`、`BRANCH_COL_WIDTH`
每一個呼叫點都有同一個問題，只是目前只有 `branch` 欄真的撞到。

**這是一行的修法，不是抽一層表格。**排 016。
